# Ex. No.2 - SIMULATION ANALYSIS ON SLIDER CRANK MECHANISM

## DATE: 12.3.2026
## AIM:
###   To determine & simulate the displacement & velocity analysis for the given slider crank mechanism. 
###   An engine mechanism is shown. The Crank CB = 200mm and the connecting rod BA = 600mm. In the position shown, the crankshaft has a speed of 50 rad/s and an angular acceleration of 800 rad/s2


## REQUIREMENTS:
###   ●	Mech Analyzer software.
###   ●	Processor: Minimum 1.5 GHz
###   ●	RAM: Minimum 512 MB
###   ●	Operating System: Windows XP, Windows Vista, Windows 7, Windows 8 or higher.
###   ●	Dependencies: Microsoft .Net 2.0 framework
###   ●	Mini Drafter.
###   ●	Geometry instruments.

PROCEDURE:
Configuration Diagram
Assume scale 1:10
1. Draw a ho0rizontal reference line and mark the fixed point C on the line.
2. From point C, draw the crank CB = 20 mm (since actual length 200 mm with scale 1:10) at an angle of 120° to the horizontal.
3. Mark point B at the end of the crank CB.
4. With B as centre and radius 60 mm (connecting rod BA = 600 mm, scaled to 60 mm), draw an arc.
5. The arc intersects the horizontal line at A. Mark this point A which represents the slider position.
6. Join B and A to form the connecting rod BA.
7. The figure C-B-A represents the configuration diagram of the slider crank mechanism.

Velocity Diagram
Scale: 10 m/s = 100 mm (assumed)
1. Take point c as the reference point in the velocity diagram since point C is fixed.
2. Draw vector bc perpendicular to crank CB. The length of bc represents the velocity of point B with respect to C.
3. From point b, draw a line perpendicular to connecting rod BA.
4. From point c, draw a horizontal line representing the direction of motion of the slider A.
5. The intersection of the two lines gives point a.
6. Join c to a to complete the velocity diagram.
7. Measure the lengths of the vectors to determine the velocity of slider A and angular velocity of connecting rod BA.
